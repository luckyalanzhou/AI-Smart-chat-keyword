# 快捷消息

运行于 iOS Scripting 的离线快捷消息键盘。选择分类，点选短句即可填入聊天输入框，由你确认发送。

## 功能

- 本地 SQLite 消息库内置 510 条内容：无畏契约回怼、不带脏字、笑话、脑筋急转弯、聊天接梗、夸夸和日常用语。
- 在脚本中新增、编辑消息和分类，设置默认分类、分类显示与按键音。
- 脑筋急转弯的题目和答案分别查看、分别填入。

## 安装与使用

1. 将项目导入 Scripting，运行脚本管理消息。
2. 在 iOS「设置 → 通用 → 键盘 → 键盘 → 添加新键盘」中启用 Scripting。
3. 在聊天输入框切换到 Scripting 键盘并选择本脚本，按分类浏览、翻页，点选消息填入。

分类和消息的修改在重新打开键盘后生效。自定义键盘为 Scripting Pro 功能，详见[官方说明](https://scriptingapp.github.io/zh/guide/Custom%20Keyboard)。

## 数据与隐私

消息与设置保存在 Scripting 本机共享目录的 SQLite 数据库中，更新内置词库会保留自定义修改。全部功能离线使用，不读取聊天记录或剪贴板。
