# 智能聊天键盘

运行于 iOS Scripting 的智能回复脚本。粘贴聊天内容后生成候选回复，点选即可插入；脚本不会自动发送消息。

## 功能

- 在脚本设置回复偏好，并配置 AI 服务商/API Key，或连接 ChatGPT 账号计划。
- 键盘识别聊天记录中的对方最新消息，支持补充上下文，并生成三条回复候选。
- 网络或模型请求失败时提供本地备用回复。

## 安装与使用

1. 将项目导入 iOS 的 Scripting 应用并运行 `index.tsx`。
2. 在设置页配置回复偏好和 AI 接入方式；使用 ChatGPT 账号计划时，完成账号授权并选择可用模型。
3. 按 iOS 提示启用 Scripting 键盘及所需权限，在聊天应用中切换到该键盘。
4. 粘贴对方消息或聊天记录，生成回复后点选一条插入；发送前可自行修改并确认。

## 数据与隐私

没有项目自建后端。用户主动粘贴/输入并生成回复时，相关消息、可选上下文和回复偏好会发送到所选 AI 服务。服务商 API Key 保存在 Scripting 共享存储；ChatGPT OAuth 凭据保存在系统钥匙串。ChatGPT 计划用量与 OpenAI API 账单分开。
